# E-Commerce Platform

A full-featured e-commerce platform built with Next.js and Stripe integration.

## Features

- Product catalog with search and filters
- Shopping cart and checkout
- Payment processing with Stripe
- Admin dashboard

## Tech Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Stripe API
